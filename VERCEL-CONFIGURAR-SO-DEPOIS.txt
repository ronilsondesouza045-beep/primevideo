CONFIGURAÇÃO VERCEL • IMVU ROOM LIVE V16.4.1 • PRODUÇÃO REAL
===========================================================

Esta versão NÃO cria dados fictícios quando faltam variáveis.
Se a infraestrutura estiver incompleta, o catálogo informa que o serviço real ainda não está pronto.

No projeto da Vercel configure como Environment Variables/Secrets:

OBRIGATÓRIO PARA O CATÁLOGO ONLINE
- IMVU_CLOUD_WORKER_TOKEN
- UPSTASH_REDIS_REST_URL
- UPSTASH_REDIS_REST_TOKEN

JÁ USADO PELO LOGIN DO SITE
- JWT_SECRET

SOMENTE SE AINDA USAR O RELAY/PAINEL LOCAL ANTIGO
- IMVU_RELAY_TOKEN
- IMVU_RELAY_OFFLINE_AFTER_MS=15000

OPCIONAL PARA O WORKER
- IMVU_CLOUD_WORKER_OFFLINE_MS=30000

IMPORTANTE
- O mesmo IMVU_CLOUD_WORKER_TOKEN deve ser configurado no backend do site e no worker permanente.
- Não coloque senhas/tokens reais no GitHub público.
- A conta IMVU do bot fica somente no ambiente do worker permanente, nunca no frontend/Vercel.
